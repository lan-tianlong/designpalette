# DesignPalette

> 面向室内设计师的专业配色与材质搭配工具集

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![Version](https://img.shields.io/badge/version-1.0.0-green.svg)](https://github.com/lan-tianlong/designpalette)

## 简介

DesignPalette 是一个专为室内设计师打造的 Web 工具集，帮助设计师快速：

**Last Updated:** 2026-08-10

- 🎨 **生成配色方案** — 覆盖 8 大室内设计风格，每种风格包含多套专业配色
- 🧱 **搭配材质方案** — 按空间类型和预算档次推荐材质组合
- 🏠 **空间预览** — 实时预览墙面 + 地面配色效果

## 功能

### 配色方案
| 风格 | 配色数量 | 说明 |
|------|---------|------|
| 现代极简 | 3 套 | 黑白灰经典，理性克制 |
| 北欧自然 | 2 套 | 清新通透，木质温暖 |
| 日式侘寂 | 1 套 | 禅意米灰，时光沉淀 |
| 工业Loft | 1 套 | 水泥钢筋，粗犷美学 |
| 轻奢现代 | 1 套 | 香槟金配，优雅高级 |
| 地中海风情 | 1 套 | 海蓝纯白，浪漫悠闲 |
| 新中式 | 1 套 | 水墨丹青，东方韵味 |
| 中古复古 | 1 套 | 柚木年代，复古温度 |

每套配色包含 5 个主色 + 使用建议（墙面、家具、点缀等）

### 材质搭配
- 6 个室内空间类型：客厅、卧室、厨房、卫生间、书房、餐厅
- 3 个预算档次：经济型、中档、高档
- 每种组合给出具体材质名称和搭配建议

### 场景预览
- 选中配色后自动渲染房间配色预览
- 直观感受墙面 + 地面的色彩搭配效果

## 本地运行

无需任何构建工具，直接在浏览器中打开 `index.html` 即可使用。

```bash
# 方式一：直接打开
open index.html

# 方式二：本地服务器
python -m http.server 8000
# 访问 http://localhost:8000
```
